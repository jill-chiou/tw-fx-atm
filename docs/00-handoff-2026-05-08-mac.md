## 今天討論到的重要決策

### 直線距離 vs 步行距離
選擇直線距離（Haversine）的原因：
- 步行距離需要每筆打 routing API，1,939 筆同時算很慢
- ATM finder 使用情境（幾百公尺內）直線 vs 步行差異不大
- Google Maps「附近」排序也是直線距離，只有點導航才算路線
- 工程原則：「夠好就好」，不為邊緣案例犧牲整體效能

### TGOS 服務說明
- **批次地址比對**：portal 服務，上傳 CSV → 等處理 → 下載結果，無程式 API
- **TGOS MAP API**：JavaScript SDK，可取代 OpenStreetMap 底圖（未來可選）
- credentials 存在 `.env`（gitignored），格式見 `.env.example`
- 單日上限 1 萬筆，無使用期限
