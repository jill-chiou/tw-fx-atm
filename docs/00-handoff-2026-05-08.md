## 這次修了什麼（全部）

### 1. parse_pdf.py — 銀行名稱 `#N/A`（代號 012）

**問題**：PDF 由 Excel 匯出，代號 012（台北富邦商業銀行）的 VLOOKUP 公式錯誤，名稱欄印出 `#N/A`。

**修法**：在 parse_pdf.py 加對照表直接補正：
```python
BANK_NAME_FIX = {"012": "台北富邦商業銀行"}
```

---

### 2. parse_pdf.py — 空代號（22 筆台新銀行）

**問題**：PDF 跨頁合併儲存格，pdfplumber 一次只讀一頁，新頁第一行的代號/銀行名稱讀出空值。

**修法**：向前填充：
```python
last_code = last_bank = ""
for row in rows:
    if row[0]:
        last_code, last_bank = row[0], row[1]
    else:
        row[0], row[1] = last_code, last_bank
```

---

### 3. geocode.py — 區名含「鎮/市」字，regex 提前停止

**問題**：`前鎮區`、`平鎮區`、`新市區` 等，「鎮」和「市」讓原本的停止條件提前觸發，query 變成 `區X路`，Nominatim 查不到。

**修法**：區段 pattern 從 `[^區鄉鎮市]+[區鄉鎮市]` 改成：

```python
r'(?:.+(?:[區鄉鎮]|(?<![區鄉鎮])市))?'
```

邏輯：貪婪匹配 + 負向回顧斷言（lookbehind），確保「市」只在不跟在 區鄉鎮 後面時才當區名結尾，避免把 `信義區市府路` 的 `市` 誤認為區名結尾。
