### 4. 架構討論：source of truth + 資料庫

**討論結論：**

- **不切換官網作為 source of truth**：geocoding 成本高、穩定性差，17 家銀行各自維護風險大
- **FISC 繼續當骨幹**：location + geocoding，月更，格式統一
- **官網角色**：補充幣別資訊 + 補 FISC 缺漏（gap B，待查）
- **加 SQLite 資料庫**：值得做，目的有二：
  1. 實際用途：incremental update、source 追蹤、SQL JOIN 比 Python dict 操作清楚
  2. 推甄展示：完整 data pipeline（ETL → DB → JSON export → 前端）
  - 計畫：FISC → `atm_locations` table；各銀行爬蟲 → `bank_currencies` table；merge → view；export JSON 給前端
  - 前端邏輯不變，只換資料產生方式
