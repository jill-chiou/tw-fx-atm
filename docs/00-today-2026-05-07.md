## 帶回家的動作：把 GitHub repo clone 到家裡的電腦（Mac）

> Mac 上用 `python3` / `pip3`，其他指令完全一樣。中文在 Mac 終端機會正常顯示，不會亂碼。

### 1. 確認環境

```bash
python3 --version   # 需要 3.10+
git --version
```

### 2. Clone repo

```bash
git clone https://github.com/intomoonlight/tw-fx-atm.git
cd tw-fx-atm
```

### 3. 安裝 Python 套件

```bash
pip3 install pdfplumber
```

（geocode.py 只用標準函式庫，不需要額外安裝）

### 4. 跑 geocoding

IP 是家裡的乾淨 IP，不會有今天的 429 封鎖遺留問題：

```bash
python3 -u scripts/geocode.py
```

約 36 分鐘。如果中途還是遇到 429，腳本會自動等 60 秒重試，不需要手動處理。

### 5. 把 PDF 放回去（如果需要重新解析）

`data/raw/atmfc.pdf` 沒有推進 GitHub。如果只是跑 geocoding，不需要 PDF；如果要重新跑 parse_pdf.py，才需要把 PDF 手動複製進 `data/raw/`。

## 今天學到的關鍵概念

| 概念 | 在哪裡用到 |
|------|-----------|
| pdfplumber 幾何解析 | parse_pdf.py |
| utf-8-sig（BOM）| CSV 輸出，給 Excel 看 |
| Regular Expression 命名群組 `(?P<name>...)` | 地址解析 |
| HTTP GET / urlencode | Nominatim API 呼叫 |
| Rate Limiting（sleep 1.1s）| 尊重免費 API 使用條款 |
| try/except + timeout | 防禦性程式設計 |
| Separation of Concerns | 每層可獨立替換（geocoder 之後可換 TGOS）|
| Python -u（unbuffered）| 讓重導向的 log 即時寫入 |
